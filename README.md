# CJPsAddin 互動教材

CJPsAddin 是一個 Excel 增益集，提供篩選、資料比對、資料收集、格式整理等功能。

這裡是它的互動教材，可以直接在瀏覽器裡練習，不需要安裝 Excel：

**👉 [開始練習](https://foolkidchang.github.io/CJPsAddin/)**

| 單元 | 內容 |
|---|---|
| 篩選強化 | 用複製或分號分隔的方式，一次篩出多個值（Alt+1／Alt+2／Alt+3） |
| 兩表比對 | 用 Key 判斷兩張表「有沒有」這筆資料 |
| 單表比對 | 同一組 Key 的資料「一不一樣」 |
| 資料收集 | 把多個檔案中 Key 相同的資料帶回同一張總表 |
| 小測驗 | 12 題課後複習 |

功能介紹：[foolkidchang.wordpress.com](https://foolkidchang.wordpress.com/)

增益集與練習檔的下載將於之後提供。
