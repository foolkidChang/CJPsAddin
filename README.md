# CJP 增益集 CJPsAddin｜Excel VBA Tools (附教學)

CJPsAddin (CJP 增益集、CJP's VBA Tools) 是一個 Excel VBA Add-in，提供篩選、資料比對、資料收集、資料拆檔、格式整理等功能。

這裡是它的教學與線上練習，可以直接在瀏覽器裡操作，不需要安裝 Excel：

**👉 [開始練習](https://foolkidchang.github.io/CJPsAddin/)**

| 單元 | 內容 |
|---|---|
| 篩選強化 | 用複製或分號分隔的方式，一次篩出多個值 (Alt+1／Alt+2／Alt+3) |
| 兩表比對 | 用 Key 判斷兩張表「有沒有」這筆資料 |
| 單表比對 | 同一組 Key 的資料「一不一樣」 |
| 多檔收集 | 把多個檔案中 Key 相同的資料帶回同一張總表 |
| 單檔收集 | 依分類規則表 (可用萬用字元) 幫資料分類，可當批次 VLOOKUP |
| 資料拆檔 | 依 Key 值欄把一張表拆成多個檔案，附設定視窗截圖與練習檔下載 |
| 樞紐明細 | 雙擊樞紐分析表的數值產生明細時，自動記下來源與篩選條件 (預設開啟) |
| 小測驗 | 20 題，學完複習 |

增益集下載：網站總覽的「安裝方式」，或直接下載 [CJPsAddin_v1.12.zip](files/CJPsAddin_v1.12.zip) (內含 `CJPsAddin.xla` 與安裝程式，解壓縮後執行安裝程式)。練習檔可以在各單元的「開始練習」下載 (篩選強化、兩表比對、單表比對、資料拆檔)。
