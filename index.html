EXCEL 增益集 · 互動練習

不必懂程式，也能用上 VBA 的威力

一個上班族，寫給上班族的 Excel 增益集

CJPsAddin 安裝後每次開 Excel 自動載入。本教材把最常用的功能做成可以在網頁上直接操作的練習。

安裝方式

執行一次安裝程式，之後每次開 Excel 都會自動載入，不用再設定。

📦下載檔案準備中：增益集、安裝程式與練習檔將於之後提供。
步驟 1

關閉 Excel，執行安裝檔

CJPsAddin_Installer_v1.11.cmd，按 Y

步驟 2

重新開啟 Excel

「增益集」索引標籤出現三組選單

步驟 3

開始練習

從下方卡片或上方頁簽選一個練習單元

快速存取工具列（安裝時自動加入）
Alt+1完全比對
Alt+2模糊比對
Alt+3取消所有篩選

工具列前 3 個按鈕會自動對應 Alt+1～3。

安裝程式做了哪些事

  1. 複製增益集到 D:\VBA（失敗改用 C:\VBA），設為唯讀
  2. 寫入 Excel 啟動設定，開 Excel 自動載入
  3. 快速存取工具列加入 3 個按鈕（Alt+1～3）
  4. 安裝資料夾加入 Excel 信任位置
  5. 「啟用所有巨集」會改成「停用並通知」，只收緊、不放寬
  6. 不覆寫公司的 Office 安全性原則
  7. 產生診斷報告 InstallDiagnostic.txt

安裝失敗時，請查看安裝程式旁產生的 InstallDiagnostic.txt，裡面記錄了每個步驟的結果。

練習 1

篩選強化

這個功能在做什麼

Excel 內建的篩選，要在下拉清單裡一個一個勾。篩選強化讓你把一串值直接當條件：複製幾個儲存格，或輸入用分號分隔的文字，按一次 Alt+1 就篩好。

適合這些時候用

  • 主管傳來一串客戶編號，要從大表裡把這些人挑出來
  • 要篩的值有十幾個，散在下拉清單的不同位置
  • 想找名稱包含某幾個關鍵字的資料
  • 套了好幾欄篩選，想一次全部取消

練完你會

  • 用複製或輸入兩種方式帶入多個條件
  • 分辨什麼時候用完全比對、什麼時候用模糊比對
  • 處理資料本身含有分號的情況
  • 知道數值欄位不能用模糊比對

開始練習

把條件複製過來，或在輸入框用 半形分號 ; 分隔，一次篩出多個值。先選題目，再照步驟操作。

題目

D2
點儲存格＝選欄位　▾＝原生篩選

表格為教學用範例資料。

完全比對 vs 模糊比對

完全 Alt+1模糊 Alt+2
比對方式值完全相同包含關鍵字
大小寫、前後空白都忽略
數值欄位可以找不到
篩空白儲存格輸入框直接按「確定」

要記住的 3 件事

  1. 沒複製東西 → 跳出輸入框，用 ; 分隔
  2. 複製內容含 ; → 程式會問：分號是分隔符號還是資料？
  3. 執行前會先清掉所有既有篩選
練習 2

兩表比對

這個功能在做什麼

兩張表用同一個 Key（例如客戶編號）對照，在每一列標上 兩表皆有、僅在A表 或 僅在B表。它只看這筆資料有沒有，不比較其他欄位的內容。

適合這些時候用

  • 這個月和上個月的名單，誰是新增、誰不見了
  • 系統匯出的清單和手上的對帳表，有沒有漏掉的
  • 兩份名單合併前，先確認差在哪幾筆
  • 原本要用 VLOOKUP 一筆一筆查「找不找得到」

練完你會

  • 選對 Key，包含多欄組成的 Key
  • 兩張表欄位順序不同時，也能正確對應
  • 看懂「_有重複項」，以及重複資料選項的差別
  • 判斷什麼時候該接著用單表比對

開始練習

選一題，點表頭設定 Key（點的順序＝Key 的順序），再按「執行兩表比對」。

格式：單一 Key A9；多個 Key A;B;9（最後是標題列）

後綴 …_有重複項＝Key 有重複
練習 3

單表比對

這個功能在做什麼

把兩份資料貼在同一張表，指定 Key 和要比較的欄位。程式會依 Key 排序，相同 Key 的列互相比較，內容不一樣的格子標成粉紅，一眼就看出差在哪裡。

適合這些時候用

  • 兩個系統的客戶資料，檢查電話、地址有沒有不一樣
  • 同一批訂單被重複匯入，金額有沒有被改過
  • 新舊兩版報表，逐筆核對數字
  • 兩表比對後兩邊都剩一些「僅在」，想找出是哪一欄打錯

練完你會

  • 分清楚哪些欄當 Key、哪些欄拿來比對
  • 看懂粉紅、灰色、藍字、分隔線四種標記
  • 調整大小寫、文字與數值的比對規則
  • 用統計列判斷問題出在哪一欄

開始練習

選一題，點表頭切換 Key／比對，再按「執行單表比對」。結果的顏色代表：

粉紅 資料不一致 灰色整列 找不到配對 藍色斜體 同 Key 第 3 筆起 分隔線 換一組 Key

工作表點表頭切換：Key → 比對 → 取消
左上角綠色三角形＝文字格式的數字
練習 4

多檔收集

這個功能在做什麼

先開好總表，再選好幾個匯入檔案。程式會在每個檔案裡找 Key 相同的資料，把指定的欄位帶回總表。可以想成進階版的 VLOOKUP：Key 和要帶回的欄位都可以是多欄，一次處理多個檔案。它在功能選單的「資料收集」群組裡，舊文章稱為「資料合併」。資料都在同一個檔案、只是要依規則對照時，用單檔收集。

適合這些時候用

  • 把總表拆給各單位填寫，收回來後要合併回同一張表
  • 金額、數量分散在不同部門的檔案，要彙整成一張
  • 各門市的月報要彙整成全公司總表
  • 各單位處理完案件後清空待辦欄，要同步回總表

練完你會

  • 正確填寫 Key值組成欄與資料回收欄
  • 看懂執行紀錄裡的 OK 與 (1/2)
  • 依情境選擇四個選項
  • 從只有標題的空白總表，彙整出完整資料

兩個欄位怎麼填

欄位單一欄多欄
Key值組成欄
哪些欄位可以組出唯一值		A3A;B;3
資料回收欄
哪些欄位要帶回來		CC;D
  • Key 最後的數字是標題列，不是資料起始列
  • 資料回收欄只寫欄名，列號沿用 Key 的標題列
  • 匯入檔案是用標題文字找欄位：欄位順序、位置可以和總表不同，但標題文字要一模一樣

四個選項

選項什麼時候勾
一、資料回收欄之資料為空值時，仍要寫入空白也是正確答案，例如清空代表已處理
二、Key值有重複時，在資料被覆蓋前，需跳出提示每個 Key 應該只出現一次，想抓出重複填寫
三、如果Key值不存在於總表，將該筆資料新增於總表最下方列允許各單位自行新增資料；或總表只留標題，全部資料由匯入檔彙整
四、用總表工作表名稱，在各匯入檔案中找尋資料所在工作表匯入檔有好幾張工作表，不確定存檔時停在哪一張

開始練習

選一題，在總表點表頭切換 Key／回收，勾選需要的選項，再按「執行資料收集」。下方的匯入檔案就是會被讀取的內容。

總表點表頭切換：Key → 回收 → 取消
黃底＝這次寫入的格子　藍色列號＝新增的列

練習 5

    
單檔收集

  


  

    
    

      
這個功能在做什麼

      
準備一張待分類資料和一張分類規則表。程式拿每一筆資料的 Key 去規則表比對，把符合那條規則的值寫回來。可以當成批次 VLOOKUP；而且規則表的 Key 可以用 萬用字元，例如「*計程車*＝交通費」，一條規則就能涵蓋很多種寫法。程式內部的名稱是「資料分類」。

      

        

          
適合這些時候用

          
    
            
  • 依商品代碼對照表，幫交易明細補上商品名稱、類別
    • 
            
  • 依摘要裡的關鍵字，把費用自動歸類
    • 
            
  • 依號碼開頭判斷類型，例如 09 開頭是手機
    • 
            
  • 依「區域＋商品」的組合，套用不同的獎金比例
    • 
          

        

        

          
練完你會

          
    
            
  • 設定兩張表各自的 Key 與填入、來源欄
    • 
            
  • 用 *、?、# 寫分類規則
    • 
            
  • 安排規則的先後順序，並決定要不要帶回最後一項相符者
    • 
            
  • 看懂並處理 !Not Found!
    • 
          

        

      

    

  


  

    

      
四個欄位怎麼填

      

      

        
表欄位範例

        
待分類資料Key值組成欄B1／A;B;1

        
分類填入欄（結果寫在這裡）D／D;E

        
分類規則表Key值組成欄（可用萬用字元）A1／A;B;1

        
分類來源欄（要帶回的值）B／B;C

      

      
    
        
  • Key 最後的數字是標題列，兩張表的標題列可以不同
    • 
        
  • 分類填入欄和分類來源欄的欄數要一樣，依順序一對一帶回
    • 
        
  • 兩張表的 Key 欄數也應該一樣
    • 
      

    

    

      
規則表可以用的萬用字元

      

      

        
寫法意思例子

        
*任意多個字（也可以沒有）*計程車*＝包含「計程車」

        
?任一個字P00?＝P001～P009、P00A…

        
#任一個數字09########＝09 開頭的 10 位數字

        
[ABC]括號裡的任一個字[AB]*＝A 或 B 開頭

        
[!A]不是括號裡的字[!0]*＝不是 0 開頭

      

      
比對時不分大小寫。要找真正的 *、?、# 符號，寫成 [*]、[?]、[#]。

    2.

    3.
