開始之前

安裝方式

執行一次安裝程式，之後每次開 Excel 都會自動載入，不用再設定。

📦下載檔案準備中：增益集、安裝程式與練習檔將於之後提供。
步驟 1

關閉 Excel，執行安裝檔

CJPsAddin_Installer_v1.11.cmd，按 Y

步驟 2

重新開啟 Excel

「增益集」索引標籤出現三組選單

步驟 3

開始練習

從上方頁簽選一個練習單元

快速存取工具列（安裝時自動加入）
Alt+1完全比對
Alt+2模糊比對
Alt+3取消所有篩選

工具列前 3 個按鈕會自動對應 Alt+1～3。

安裝程式做了哪些事

  1. 複製增益集到 D:\VBA（失敗改用 C:\VBA），設為唯讀
  2. 寫入 Excel 啟動設定，開 Excel 自動載入
  3. 快速存取工具列加入 3 個按鈕（Alt+1～3）
  4. 安裝資料夾加入 Excel 信任位置
  5. 「啟用所有巨集」會改成「停用並通知」，只收緊、不放寬
  6. 不覆寫公司的 Office 安全性原則
  7. 產生診斷報告 InstallDiagnostic.txt

安裝失敗時，請查看安裝程式旁產生的 InstallDiagnostic.txt，裡面記錄了每個步驟的結果。

練習 1

篩選強化

把條件複製過來，或在輸入框用 半形分號 ; 分隔，一次篩出多個值。

題目

D2
點儲存格＝選欄位　▾＝原生篩選

表格為教學用範例資料。

完全比對 vs 模糊比對

完全 Alt+1模糊 Alt+2
比對方式值完全相同包含關鍵字
大小寫、前後空白都忽略
數值欄位可以找不到
篩空白儲存格輸入框直接按「確定」

要記住的 3 件事

  1. 沒複製東西 → 跳出輸入框，用 ; 分隔
  2. 複製內容含 ; → 程式會問：分號是分隔符號還是資料？
  3. 執行前會先清掉所有既有篩選
練習 2

兩表比對

用 Key 判斷每一筆是 兩表皆有、僅在A表 或 僅在B表。點表頭設定 Key，點的順序＝Key 的順序。

格式：單一 Key A9；多個 Key A;B;9（最後是標題列）

後綴 …_有重複項＝Key 有重複
練習 3

單表比對

同一張表裡，相同 Key 的資料是否一致？程式會依 Key 排序，再上色標示。

粉紅 資料不一致 灰色整列 找不到配對 藍色斜體 同 Key 第 3 筆起 分隔線 換一組 Key

工作表點表頭切換：Key → 比對 → 取消
左上角綠色三角形＝文字格式的數字
