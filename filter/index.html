Excel 一次篩選多個值：複製一串編號，按 Alt+1 就篩好

主管傳來十幾個客戶編號，要從幾千列的大表裡把這些人挑出來。Excel 內建的篩選要在下拉清單裡一個一個勾，值一多就很容易漏。CJP 增益集 (CJPsAddin，免費的 Excel VBA Add-in) 的篩選強化，讓你把一串值直接當條件：複製幾個儲存格，或輸入用分號分隔的文字，按一次 Alt+1 就篩好。

在網頁上直接試 (不用安裝) → 下載增益集 練習檔 (Excel)

適合這些時候用

  • 主管傳來一串客戶編號，要從大表裡把這些人挑出來
  • 要篩的值有十幾個，散在下拉清單的不同位置
  • 想找名稱包含某幾個關鍵字的資料
  • 套了好幾欄篩選，想一次全部取消

Excel 內建的做法

  • 篩選下拉清單：一個一個勾。可以用搜尋框找，但一次只能搜一個值，要重複好幾次
  • 進階篩選：要先在旁邊做一個「條件範圍」(標題＋每列一個值)，再到「資料 → 進階」選範圍，步驟比較多
  • FILTER 公式 (Microsoft 365)：條件放在 E2:E5 時，可以寫 
    =FILTER(A2:C100, ISNUMBER(MATCH(A2:A100, E2:E5, 0)))
    結果會出現在另一個位置，不是在原本的表上篩選

用 CJP 增益集：3 個步驟

  1. 點一下要篩選的欄位裡任一個儲存格 (工作表要已經設定篩選)
  2. 複製要篩的值 (例如主管信裡的一串編號)；或不複製，等一下在輸入框用半形分號分隔輸入，例如 001;003;005
  3. 按 Alt+1，表格只留下這些值
快捷鍵功能說明
Alt+1完全比對值完全相同才留下；大小寫、前後空白都忽略；數值欄位也可以用
Alt+2模糊比對包含任一關鍵字就留下；只適用文字，數值欄位會找不到
Alt+3取消所有篩選一次取消工作表上所有欄位的篩選，並回到目前選取的位置

快捷鍵是安裝程式放在「快速存取工具列」前 3 個的按鈕。新版 Microsoft 365 的按鈕可能排到後面，請照這裡調整順序。

常見問題

按 Alt+1 之前，已經篩過別的欄位了怎麼辦？

不用先取消。執行前會先清掉所有既有的篩選，再依新的條件篩選。

要篩的資料本身就有分號，例如「A01;特規」？

複製的內容含有分號時，程式會問分號是分隔符號還是資料：要找剛好是「A01;特規」的資料，選「否，請直接篩選」。這種資料只能用複製的方式帶入。

在數量欄用模糊比對搜「2」，為什麼找不到？

模糊比對只適用文字。數值請用完全比對 (Alt+1)，或先把欄位轉成文字。

可以篩出空白的儲存格嗎？

可以。沒有複製任何東西時按 Alt+1，跳出的輸入框裡有一行預設文字，直接按「確定」就是篩選空白儲存格。要中止請按「取消」或 Esc。

要付費嗎？公司電腦可以裝嗎？

免費。安裝方式和注意事項 (例如公司的巨集安全性設定) 請看安裝方式。
